## ✨ Features

- 🎨 Cozy winter palette with latte, cinnamon, and frosty blue tones

- 🎯 WCAG-compliant contrast for accessibility
- ✨ Hardcoded accent colors that override user settings

## 📦 Installation

### From Obsidian Community Themes

1. Open Obsidian Settings
2. Go to **Appearance** → **Themes** → **Manage**
3. [Find Winter Café in the community store](https://community.obsidian.md/themes/winter-cafe)
4. Click **Install** and then **Use**

> Note: the theme is under review in the **Obsidian** community store

### Manual Installation

1. Download the `theme.css` and `manifest.json` files
2. Create a folder called `Winter Café` in your `.obsidian/themes/` directory
3. Place both files in this folder
4. Enable the theme in Obsidian Settings → Appearance → Themes

<a id="customization"></a>

## 🛠️ Customization

### Changing Colors

You can customize the theme by editing the CSS variables in `theme.css`:

```css
--winter-cinnamon: #c9956b; /* Change to your preferred cinnamon */
--winter-caramel: #d4a373; /* Change to your preferred caramel */
--winter-ice: #7fb8cc; /* Change to your preferred ice blue */
```

### Recommended Accent Color

For the best experience, set your Obsidian accent color to:

- RGB: 201, 149, 107
- HEX: #c9956b
  Note: The theme hardcodes accent colors, so user settings will be overridden.
